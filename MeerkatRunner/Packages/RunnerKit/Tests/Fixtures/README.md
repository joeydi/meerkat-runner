# Detection fixtures

Each folder is a minimal project. `expected.json` lists the ranked proposals the detectors must
return, in order: `label`, `argv` or `shell`, `resolvedScript`, `source`, `framework`,
`predictedPort`, `notes`. `FixtureTests.testAllFixtures` runs every folder that has an
`expected.json`.

Detectors read these files and **never execute them**: `malicious-curl-sh` must be proposed
verbatim and never run.

Covered (AGENTS.md §10): next-pnpm, vite-npm, astro-yarn, remix-bun, pnpm-monorepo (2 workspaces),
turbo-monorepo, rails-bin-dev, django-venv, flask (port 5000 warning), laravel, procfile-dev,
makefile-targets, justfile, compose, npm-predev (`predev` hook), malicious-curl-sh.

Generated by the tests instead of committed: an unreadable `package.json` (`chmod 000`) and a 5 MB
`package.json` (size cap).
